# JEE & NEET Test Series Platform

A modern, dark-themed test series application designed for JEE and NEET aspirants. Built for seamless exam simulation, detailed analytics, and practice tracking.

## Tech Stack
- **Frontend:** React, Tailwind CSS, Lucide Icons
- **Backend & Database:** Supabase (PostgreSQL)
- **Deployment:** Vercel / Netlify

## Features
- **Exam Engine:** Full-screen exam UI with countdown timer, question palette, and review tagging.
- **Analytics Dashboard:** Performance tracking, subject-wise accuracy, and score history.
- **Question Bank:** Categorized by Subject (Physics, Chemistry, Math, Biology) and Exam Type (JEE Main, JEE Advanced, NEET).

## Database Schema Overview
- `questions` — Contains question text, options, correct answers, subject tags, and explanations.
- `test_attempts` — Stores user attempts, scores, time taken, and detailed option logs.
